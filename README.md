# 温｜手机 Web App

这是一个移动优先的 GPT 陪伴网页项目。

## 已有功能
- 微信式聊天气泡
- GPT 后端真实对话
- “温”的人格提示词
- 温的日记：根据当天聊天生成第一人称日记
- 我的日记
- 手机浏览器可安装为 PWA
- API Key 只放服务端环境变量，不放网页前端

## 本地运行
1. 安装 Node.js 18+
2. 在项目目录执行 `npm install`
3. 复制 `.env.example` 为 `.env`
4. 把 OpenAI API Key 填到 `.env`
5. 执行 `npm run dev`
6. 手机和电脑在同一 Wi-Fi 时，可用电脑的局域网地址打开；正式使用建议部署到支持 Node 的服务器。

OpenAI 官方文档说明 API Key 应作为服务端秘密保存，不要暴露在浏览器代码中。
